Ứng dụng đọc livestream công khai, không cần cookie hay mật khẩu TikTok. Dữ liệu lưu local và data/ không được đưa lên GitHub.

git clone https://github.com/HuppoTa/tiktoklivetracking.git
cd tiktoklivetracking
npm install
npm start

# Mở http://localhost:3000
